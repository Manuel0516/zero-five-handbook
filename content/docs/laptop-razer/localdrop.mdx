## Daily use and service commands

Clipboard text syncs automatically between Razer and MacBook while both daemons
and clipboard polling are running. Copy text normally, then paste on the other
computer. On iPhone, run the configured Shortcut to send its clipboard to Razer;
ordinary iPhone copy/paste does not itself trigger LocalDrop.

On Razer:

```bash
# Start now; enable automatic startup with the graphical session.
systemctl --user enable --now localdrop.service

# Restart after changing the private configuration or reconnecting the session.
systemctl --user restart localdrop.service

# Service state and recent diagnostic messages.
systemctl --user status localdrop.service --no-pager
journalctl --user -u localdrop.service -n 50 --no-pager

# Local listener health and configured MacBook peer reachability.
curl --fail --max-time 5 http://10.40.0.12:8765/health
cd ~/projects/localdrop
python main.py ping

# Send a file to the configured MacBook peer.
python main.py send ~/Downloads/example.pdf

# Pause clipboard/file reception and outbound polling.
systemctl --user stop localdrop.service
```

Received files are in `~/Downloads/LocalDrop`. Replace the example filename with
an existing file. The CLI reads the existing private `config.toml`; never put the
shared token in a command or paste it into logs. A health response only checks
the listener; `ping` checks the configured peer. Run the foreground daemon only
when the service is stopped, otherwise its listening port is already occupied:

```bash
systemctl --user stop localdrop.service
cd ~/projects/localdrop
python main.py daemon
# After Ctrl+C, resume the normal service:
systemctl --user start localdrop.service
```

## Token and restore source

The existing shared token was recovered privately from retained restic snapshot
`56856c59`, without printing it. Historical NAS paths keep their names. Local
`config.toml` and the recovery copy are mode 600 and outside Git. The pack's
`config.toml.example` contains only `ENROLL_RECOVERED_TOKEN_PRIVATELY`.

Restore the pinned source and reviewed service/example separately, enroll the
same token through the private recovery path, and verify graphical-session
Wayland variables before enabling. The receive endpoint can update the clipboard
even if outbound polling is paused. HTTP 401 indicates a token mismatch; timeout
points to URL, route/firewall or listener availability. An installed package or
an active service is not inter-device acceptance.

Rollback stops/disables only the new user service and removes only its scoped
firewall rules. Preserve private configuration and downloaded files. Operational
source is `settings/razer/localdrop/`; TCP checks require explicit current targets.
