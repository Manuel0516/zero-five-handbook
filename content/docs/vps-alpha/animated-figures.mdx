# Animated Figures — YouTube AI video pipeline

Full-stack pipeline for generating faceless YouTube videos in the
"animated curiosity" style (like Whymentary), targeted at the **engineering
facts / curiosities** niche, in **English or Spanish**, fully autonomously.

## Location & repo

- Path: `~/services/animated-figures` (native, not Docker)
- Repo: https://github.com/Manuel0516/animated-figures (SSH remote on alpha)
- Venv: `.venv` inside the service folder (Python 3.11)
- Brand identity: `brand.yaml` — canvas 1920×1080@30fps, near-black
  `#0E0E10` background, off-white `#F5F3EC` ink, gold `#FFD24A` accent

## How it works

1. A code agent (Claude Code / Codex / opencode / Hermes) reads
   `prompts/master_prompt_en.txt` or `prompts/master_prompt_es.txt`,
   picks a topic, writes the narration script, and emits `project.json`
   with typed scenes:
   - `diagram` — manim animation from a declarative JSON spec
     (nodes/edges/labels/reveal order); the channel's superpower for
     engineering content (cross-sections, force diagrams, gear trains)
   - `character` — static stick-figure beat ("overview → zoom into detail")
   - `still` — AI-generated image in the MS-Paint doodle style
   - `text-card` — pure Pillow typography (key numbers, final fact)
2. `scripts/run_all.py --dir output/<slug> --lang en|es` drives the whole
   chain idempotently: images → manim clips → narration (Edge TTS) →
   animated word-by-word subtitles → `final_clean.mp4` → `final.mp4`.

Fully autonomous: no human confirmation gates. Footage scenes are
supported but never required; `visual.confirmed` is optional.

## Costs & keys

| Path | Cost | Key |
|---|---|---|
| diagram / character / text-card scenes | $0 | none |
| still scenes | $0 (free tier) / ~$0.04 img | `GEMINI_API_KEY` / `OPENROUTER_API_KEY` |
| narration | $0 | none (Edge TTS) |

`.env` lives in the service folder (see `.env.example`). Only stills need a
key; a 100%-diagram video costs $0.

## Languages

`--lang en|es` picks the Edge TTS voice automatically:
- `EDGE_TTS_VOICE_EN` (default `en-US-ChristopherNeural`)
- `EDGE_TTS_VOICE_ES` (default `es-ES-AlvaroNeural`)

Subtitles and `.srt` follow the narration language. To make a bilingual
video, run the pipeline twice (once per language) with separate output dirs.

## Rebuild / deps

```bash
cd ~/services/animated-figures
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

System packages needed for manim (pycairo) — requires sudo:

```bash
sudo apt install libcairo2-dev pkg-config fonts-dejavu-core
```

Nerd Font (JetBrainsMono) for diagram node icons is installed per-user at
`~/.local/share/fonts/` (icon glyphs in manim diagrams).

## Output

Each run produces `output/<slug>/`:
`final.mp4` (subtitles burned), `final_clean.mp4`, `subtitles.srt`,
`narration.mp3`, `word_timings.json`, plus per-scene assets.

## Playbook: generate a video

1. `cd ~/services/animated-figures`
2. Paste `prompts/master_prompt_en.txt` (or `_es`) into a code agent
3. Agent writes script + project.json, then runs:
   `python scripts/run_all.py --dir output/<slug> --lang en`
4. Upload `final.mp4` + `subtitles.srt` to YouTube

For scheduled automation, a cron job can call `run_all.py` on a
pre-generated project folder.
