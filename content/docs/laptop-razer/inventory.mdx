helper synchronizes Hyprland devices and Fcitx; the owner verified Spanish input.

## Initial inspection limits and remaining checks

The initial sandbox denied system bus and Hyprland socket access; the subsequent
live pass accessed both and supersedes those limits for the checks it completed. `nvidia-smi` could
not communicate with the driver from this session. That result does not establish
a host driver failure; repeat it in a normal terminal before diagnosing the GPU.
The session exposes a read-only root view, which does not establish that the
normal desktop root filesystem is read-only.

Run on the host and retain only reviewed, non-secret results:

```bash
hostnamectl
hyprctl configerrors
hyprctl monitors
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv,noheader
systemctl is-active docker power-profiles-daemon thermald intel-lpmd
findmnt / /home /boot
```

Check snapshots, backups, encryption recovery, Windows boot, suspend/resume,
CUDA, audio and network reachability separately. The initial baseline pass made no runtime changes. Subsequent tool installation,
Docker activation, runtime DNS repair and selective LocalDrop configuration
recovery are recorded on the development page.
