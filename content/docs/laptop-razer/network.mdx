## SSH and inspection

The MacBook SSH example now uses `Host razer` with `.12`, user `manuel` and
`ProxyJump alpha`. It is source for review; this pass did not modify another
machine's SSH configuration or enroll keys. Verify the Razer SSH server and
known-host fingerprint before first access. An old client alias does not prove
that a Razer SSH daemon is listening.

```bash
ip route get 10.40.0.2
ip route get 10.40.0.11
resolvectl status wg0
resolvectl query delta.zero-five.space macbook.zero-five.space
adig -s 10.40.0.2 razer.zero-five.space
```

Use administrator `wg show wg0 latest-handshakes` and `wg show wg0 allowed-ips`
for safe inspection. Never publish `wg showconf`, full `.conf` files or private
keys. Preserve an owner-only copy before persistent changes; roll back only the
changed route/name configuration, keeping a working SSH hop available.
