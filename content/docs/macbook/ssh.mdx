SSH is used to authenticate to **GitHub**, connect to the **Alpha VPS**, and
reach **Gamma** and **Beta** through **Delta** as a jump host. Everything lives
in `~/.ssh/`.

> **Warning:** This page documents the *configuration only*. Private keys are never stored in this handbook — generate a new key on a new machine instead of copying the old one.

---

## Keys

One ed25519 keypair is used for everything:

| File | Purpose |
|------|---------|
| `~/.ssh/id_ed25519` | Private key — **never leaves this machine** |
| `~/.ssh/id_ed25519.pub` | Public key — registered with GitHub and the VPS |

### Generate on a new machine

```bash
ssh-keygen -t ed25519 -C "manuellore05@gmail.com"
```

Then register the new public key:

1. **GitHub:** [Settings → SSH and GPG keys](https://github.com/settings/keys) → paste the output of `cat ~/.ssh/id_ed25519.pub`
2. **VPS:** `ssh-copy-id contabo` (authenticate with password once)

## Config file

The active file is `~/.ssh/config`. The focused, secret-free Zero Five fragment
is tracked at
`zero-five-infra/ssh/macbook-zero-five.config.example`; SSH does not load that
repository file automatically, so merge it into the active file rather than
editing it as though it were deployed.

Current `~/.ssh/config`:

```text
Include /Users/manuel/.colima/ssh_config

Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/id_ed25519

Host alpha
  HostName 95.111.229.142
  User manuel
  Port 2020

Host delta
  HostName 192.168.1.106
  User manuel
  Port 22
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes

Host gamma
  HostName 10.40.0.3
  User manuel
  Port 22
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes
  ProxyJump delta

Host beta
  HostName 10.40.0.4
  User root
  Port 22
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes
  ProxyJump delta
  HostKeyAlias 192.168.1.166

Host msi
  HostName 10.40.0.12
  User manuel
  Port 22
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes
  ProxyJump alpha

Host blackarch
  HostName 10.40.0.101
  User zero
  Port 22
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes
  ProxyJump delta
  HostKeyAlias 192.168.1.104
```

### Breakdown

| Entry | What it does |
|-------|--------------|
| `Include ~/.colima/ssh_config` | Added automatically by [Colima](/docs/macbook/docker) so `ssh colima` reaches the container VM — don't remove it |
| `Host github.com` | Uses the ed25519 key, loads it into the agent, and stores the passphrase in the macOS Keychain (`UseKeychain yes`) — no passphrase prompts after the first use |
| `Host alpha` | Alias for the [Alpha VPS](/docs/vps-alpha): `ssh alpha` instead of `ssh -p 2020 manuel@95.111.229.142`. Note the non-default port `2020` — see [VPS Security](/docs/vps-alpha/security) for the server side |
| `Host delta` | Direct LAN alias for Delta at `192.168.1.106`; it is the jump host for the private laptop paths |
| `Host gamma` | Connects to Gamma's private `10.40.0.3` address through `ProxyJump delta`; Gamma remains unreachable directly from outside WireGuard |
| `Host beta` | Connects as `root` to Beta's `10.40.0.4` address through `ProxyJump delta`; `HostKeyAlias 192.168.1.166` reuses the already-pinned identity of the same physical host |
| `Host msi` | Connects to the MSI's WireGuard address through Alpha |
| `Host blackarch` | Connects as `zero` to BlackArch through Delta and reuses its LAN host-key alias |
| `IdentitiesOnly yes` | Restricts each host to the explicitly selected identity instead of trying every key loaded in the agent |

## Usage

| Task | Command |
|------|---------|
| Connect to the VPS | `ssh alpha` |
| Connect to Delta | `ssh delta` |
| Connect to Gamma through Delta | `ssh gamma` |
| Connect to Beta through Delta | `ssh beta` |
| Test GitHub authentication | `ssh -T git@github.com` |
| Copy a file to the VPS | `scp file.txt alpha:~/` |
| List keys loaded in the agent | `ssh-add -l` |

## Troubleshooting

### `Permission denied (publickey)` on GitHub

1. Check the key is loaded: `ssh-add -l`
2. If empty, add it with the Keychain flag: `ssh-add --apple-use-keychain ~/.ssh/id_ed25519`
3. Confirm the public key is registered on GitHub: `ssh -T git@github.com`

### VPS connection refused

The VPS uses port `2020`, not 22 — connecting with a raw `ssh manuel@95.111.229.142` fails. Use the `alpha` alias, which sets the port.

### Gamma connection fails

Test each hop independently. `ssh delta` must work first. On Delta,
`ping -c 3 10.40.0.3` must reach Gamma over WireGuard. Then inspect the resolved
Mac configuration with `ssh -G gamma | grep -E '^(hostname|user|port|proxyjump) '`;
it should report `hostname 10.40.0.3` and `proxyjump delta`.

### Beta connection fails

Use the same hop-first diagnosis: `ssh delta` must work. On Delta,
`ping -c 3 10.40.0.4` and `nc -zvw 3 10.40.0.4 22` must succeed. Then inspect:

```bash
ssh -G beta | grep -E \
  '^(hostname|user|port|proxyjump|hostkeyalias) '
```

It must resolve to user `root`, hostname `10.40.0.4`, `proxyjump delta`, and
`hostkeyalias 192.168.1.166`. The full runbook is on the
[Beta SSH page](/docs/laptop-beta/ssh).
