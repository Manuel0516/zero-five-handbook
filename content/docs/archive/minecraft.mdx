**LynxHouse** is a modded Minecraft **Fabric 1.20.1** server. It is the one
service that runs neither in Docker nor from a git repo — bare-metal Java under
systemd, with the world data backed up as files.

| Property | Value (alpha era) |
|----------|-------|
| Address | `mc.zero-five.space` (SRV `_minecraft._tcp.mc` → 25565) |
| Minecraft | 1.20.1 (Fabric loader, `fabric-installer-0.11.2.jar`) |
| Java | OpenJDK 17 headless (Ubuntu apt) |
| Heap (alpha) | ~~`-Xms4G -Xmx8G`~~ → **moved to gamma as `-Xms2G -Xmx4G`** |
| Players | max 5, survival, easy, online mode on |
| RCON | `127.0.0.1:25575` — used by the hub-agent |

## Why it moved

Alpha's `minecraft.service` (8 GB heap ceiling ≈ the box's total RAM) was the
#1 OOM suspect once more services moved in. Alpha has since been planned as a
cleaner host. gamma has 1.1 GB free / 6.8 GB RAM and 830 GB free disk, placing
the server alongside (not inside) a ram-hungry VPS.

## Alpha unit (historical — now disabled)

`/etc/systemd/system/minecraft.service` (was enabled, boot-start):

```ini
[Unit]
Description=Minecraft Fabric Server
After=network.target

[Service]
User=manuel
WorkingDirectory=/home/manuel/services/minecraft/LynxHouse
ExecStart=/usr/bin/java -Xms4G -Xmx8G -jar fabric-server-launch.jar nogui
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

> **Retired from alpha 2026-08-23.** `~/services/minecraft/` was removed (1.1 GB)
> and `minecraft.service` disabled (see cleanup). Alpha no longer hosts Minecraft;
> the server runs on [gamma](/docs/laptop-gamma/minecraft).

The world was copied to gamma (1.1 GB, rsync over the mesh, verified byte-for-byte).
The `LynxHouse/` folder includes a stray `world ` (trailing space) and nested
`LynxHouse/LynxHouse` subdir from the original bootstrapping — preserved on both.

## Backups

The world is plain files — back up while stopped, or RCON `save-off`/`save-all`:

```bash
sudo systemctl stop minecraft
tar czf ~/backups/lynxhouse-$(date +%F).tar.gz -C ~/services/minecraft LynxHouse/world
sudo systemctl start minecraft
```
