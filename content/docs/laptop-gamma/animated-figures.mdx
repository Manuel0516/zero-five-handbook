# Animated Figures — YouTube AI video pipeline

Full-stack pipeline for generating faceless YouTube videos in the
"animated curiosity" style (like Whymentary), in the **transportation
engineering** niche: ONE iconic machine per video (plane, train, ship,
rocket, submarine...), explained in depth for **~3 minutes (450-550
words)** — what it is, how it works, why it works, real-life moments,
final fact. **Active language: English** (`--lang en`).

> **Migrated alpha → gamma 2026-08-24.** Now runs on gamma at
> `~/services/animated-figures` (native, not Docker). The VPS no longer hosts
> the pipeline.

**Design rule:** AI images are 100% visual — never contain text, labels or
numbers (image models garble them). All text lives in crisp Pillow
`text-card` scenes. Manim is disabled; `diagram`/`character` scenes
auto-convert to text-cards.

**Shorts mode:** each concept can also produce a vertical 9:16 Short
(50-60s) derived from the long script: `gen_script.py --mode short
--derive-from output/<slug>` + `run_all.py --dir <slug>-short --shorts`
(uses `brand-shorts.yaml`, 1080×1920).

## Mascot: the yellow-helmet engineer

The channel's recurring character is a **stick-figure engineer wearing a
bright yellow hard hat** (`brand.yaml` → `mascot.helmet_color`, same gold
as the accent). It exists **only in AI-generated stills** — the style is
injected automatically by `prompts/image_style.txt` into every image
prompt; there is **no manim version** of the character.

## How it works

1. A code agent (Claude Code / Codex / opencode / Hermes) reads
   `prompts/master_prompt_en.txt` or `prompts/master_prompt_es.txt`,
   picks a topic, writes the ~750-word narration script, and emits
   `project.json` with typed scenes:
   - `still` (~80%) — AI image in the MS-Paint doodle style, always
     featuring the yellow-helmet engineer
   - `text-card` (~15%) — pure Pillow typography (key numbers, final fact)
   - `diagram` (max 1-2 per video, last resort) — manim animation from a
     declarative JSON spec; kept to a minimum because the channel is
     image-first and manim renders are slow
2. `scripts/run_all.py --dir output/<slug> --lang en|es` drives the whole
   chain idempotently: images → manim clips → narration (Edge TTS) →
   animated word-by-word subtitles → `final_clean.mp4` → `final.mp4`.

Script brain: `scripts/gen_script.py` calls **gpt-5.6-luna via the ChatGPT
Codex subscription** (`chatgpt.com/backend-api/codex`, OAuth token from
`~/.hermes/auth.json`), never OpenRouter; override with `--model` or
`CODEX_SCRIPT_MODEL`.

Image validation: every still is checked after generation
(`scripts/validate_image.py`: size, decode, 16:9 aspect, not blank);
failed images are regenerated individually with an improved prompt
(`--image-retries`, default 2). Standalone check:
`python scripts/validate_image.py --dir output/<slug>`.

Fully autonomous: no human confirmation gates. Footage scenes are
supported but never required; `visual.confirmed` is optional.

## Costs & keys

| Path | Cost | Key |
|---|---|---|
| still scenes | ~$0.04 img | `OPENROUTER_API_KEY` (preferred, `seedream-4.5`) / `GEMINI_API_KEY` (free tier fallback) |
| text-card scenes | $0 | none |
| diagram scenes | $0 (compute) | none (needs manim installed) |
| narration | $0 | none (Edge TTS) |

`.env` lives in the service folder (see `.env.example`). `run_all.py`
auto-picks OpenRouter when `OPENROUTER_API_KEY` is set, else Gemini.

## Languages

`--lang en|es` picks the Edge TTS voice automatically:
- `EDGE_TTS_VOICE_EN` (default `en-US-ChristopherNeural`)
- `EDGE_TTS_VOICE_ES` (default `es-ES-AlvaroNeural`)

Subtitles and `.srt` follow the narration language. To make a bilingual
video, run the pipeline twice (once per language) with separate output dirs.

> PyYAML / Pillow (all install clean on gamma's Python 3.14). No cairo/Pango

> `python3.14-venv` (both installed 2026-08-24).

The Nerd Font (JetBrainsMono) at `~/.local/share/fonts/` is only for the

## Output

Each run produces `output/<slug>/`:
`final.mp4` (subtitles burned), `final_clean.mp4`, `subtitles.srt`,
`narration.mp3`, `word_timings.json`, plus per-scene assets.

## Playbook: generate a video

1. `ssh gamma` → `cd ~/services/animated-figures`
2. Paste `prompts/master_prompt_en.txt` (or `_es`) into a code agent
3. Agent writes script + project.json, then runs:
   `python scripts/run_all.py --dir output/<slug> --lang en`
4. Upload `final.mp4` + `subtitles.srt` to YouTube

For scheduled automation, a cron job can call `run_all.py` on a
pre-generated project folder.
