# Beatbump on Gamma

Beatbump is a SvelteKit/Go alternative frontend for YouTube Music. It runs on
Gamma with the upstream `invidious-companion` service and is available only
through the Zero Five VPN at **`https://music.zero-five.space`**.

It does not require a personal YouTube/Google account. Beatbump uses anonymous
server-side YouTube access; personal subscriptions, history, and recommendations
are therefore not available. Do not provide personal YouTube cookies or OAuth
credentials to the service.

## Architecture

```text
VPN client browser
  → AdGuard rewrite: music.zero-five.space → 10.8.0.2
  → Delta Traefik :443
  → Gamma Beatbump :8080
  → Gamma invidious-companion :8282
  → YouTube / YouTube Music
```

The hostname is deliberately **not** published in Cloudflare. DNS resolution
comes from AdGuard for clients using the Zero Five DNS path. Traefik serves the
per-name Let's Encrypt certificate as the primary certificate and the existing
Zero Five Internal CA wildcard certificate as the fallback.

## Gamma deployment

The service lives under the standard Gamma service root:

```text
~/services/beatbump/
├── compose.yaml
├── .env                 # root-equivalent secret; never commit
├── db/                  # Beatbump SQLite database
└── downloads/           # downloaded audio files
```

The containers are:

| Container | Purpose | Runtime |
|---|---|---|
| `beatbump` | Web frontend, API, playback and download management | `ghcr.io/giwty/beatbump:latest` |
| `beatbump-companion` | Generates valid YouTube playback sessions | `quay.io/invidious/invidious-companion:latest` |

The companion secret is generated locally in Gamma and shared only through the
Compose environment. The companion drops all Linux capabilities, is read-only
apart from its cache, and runs with `no-new-privileges`.

## Mobile and background playback

Open `https://music.zero-five.space` on the phone while WireGuard is active,
start playback, then lock the screen. Beatbump implements the browser Media
Session API, so supported mobile browsers expose track metadata and play,
pause, previous, next, and seek controls on the lock screen/control center.

On iOS, adding the URL to the home screen can make the experience more app-like:
Safari → Share → Add to Home Screen. The WireGuard tunnel must remain connected
while listening. Browser background-tab suspension remains a platform limitation,
so lock-screen playback is a client verification item rather than a server
health guarantee.

## Downloads

Downloads are stored in `~/services/beatbump/downloads`, not in Docker's root
filesystem or a shared NAS path. The directory is intentionally separate from
the SQLite database so it can be backed up, inspected, or removed independently.

Downloading media may have copyright and service-terms implications. Keep the
service private and use it only for content you are permitted to store.

## Hub registration

Beatbump is registered in Hub as a simple manual `web` service:

| Field | Value |
|---|---|
| URL | `https://music.zero-five.space` |
| Node | Gamma |
| Visibility | Admin/VPN users |
| Health URL | `http://10.8.0.3:8080/` |

This is deliberately independent of the planned future Hub redesign.

## Verification

From a VPN-connected client:

```bash
curl -I https://music.zero-five.space/
```

From Alpha or Delta, verify the Gamma backend directly:

```bash
curl -I http://10.8.0.3:8080/
curl -sk --resolve music.zero-five.space:443:10.8.0.2 \
  https://music.zero-five.space/
```

Verify that the exact SNI certificate is Let's Encrypt when the per-name
certificate has been issued. If that certificate is unavailable, Traefik should
fall back to the trusted Zero Five Internal CA wildcard certificate.

On Gamma:

```bash
cd ~/services/beatbump
docker compose ps
docker compose logs --tail=100 beatbump beatbump-companion
du -sh downloads db
```

## Operations and rollback

```bash
cd ~/services/beatbump
docker compose pull
docker compose up -d
docker compose ps
```

To stop the experiment without deleting its data:

```bash
docker compose down
```

To remove the containers and retain downloads/database data, use the command
above and leave the service directory in place. Remove `downloads/` only when
the downloaded collection is intentionally being deleted. The companion cache
is a disposable Docker volume and can be removed separately after stopping the
stack.
