## How a proposal here reaches reality

A design reaches verified state through the same sequence as any homelab change:

1. Agree the scope, architecture, and threat model in chat first.
2. Record the resolved design here (the proposal page).
3. Build incrementally against an active machine, verifying at each step.
4. When a component is live, split the design into a runbook/configuration page
   under the relevant machine section and update this index to point to it.

The homelab golden rules apply: no secrets in the handbook, deployment-local
config stays off the public repos, and commits accumulate on major milestones,
not per change.
