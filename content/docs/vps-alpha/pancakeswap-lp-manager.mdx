## Purpose

`pancakeswap-lp-manager` is a local read-only market-observation and research service. It helps the owner decide how to manage their own LP over a multi-year horizon by reporting live position state, fee estimates, range risk, historical observations, and candidate range analysis.

The owner remains the only person who can act on the position in their own wallet. Hermes provides analysis, not execution or authorization.

## Architecture

```text
Hermes reasoning / scheduled analysis
        │ native stdio MCP
        ▼
PancakeSwap LP Market Observer
  ├─ fresh read-only BSC RPC position reads
  ├─ read-only pending-fee collect quote
  ├─ range, trend and volatility analysis
  └─ SQLite observation/history store
```

## What reports provide

The scheduled reports show, where live data is available:

- LP value and USDC/BNB composition in USD;
- current price, ticks, opening range, normalized boundary distance, and range status;
- pending fees as a **read-only quote**, not collected income;
- measured fee samples and explicit data-history limits;
- range-risk, BNB exposure, volatility/trend evidence, and alternatives such as waiting, wider ranges, or recentering;
- a research conclusion such as `WAIT`, `WATCH`, or `REBALANCE REVIEW`—never an instruction or transaction proposal.

No projection is presented as a guaranteed return. Fee, volatility, impermanent-loss, and compounding estimates must state their data window, assumptions, and limitations.

## Operations

```bash
cd ~/services/pancakeswap-lp-manager
docker compose ps
curl -fsS http://127.0.0.1:8788/health
curl -fsS http://127.0.0.1:8788/v1/managed-position
hermes mcp test pancakeswap-lp-manager
```

To stop the observer without affecting the wallet or LP:

```bash
cd ~/services/pancakeswap-lp-manager
docker compose down
```

Do not run `docker compose down -v` unless the owner explicitly wants observation/audit history removed.
