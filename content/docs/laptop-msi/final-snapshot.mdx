1. **Choose the preservation level.** For the closest possible final snapshot,
   make an offline image of the entire internal disk to the NAS using a trusted
   imaging tool. Also keep a file-level backup for convenient Windows recovery.
   For a smaller file backup, include the essential/important rows above and
   explicitly decide which games, caches, and models to omit.
2. **Close applications and export application data.** Export Resolve projects,
   verify wallet recovery, save browser bookmarks/recovery access, and obtain
   consistent database and object-storage backups. A live home-folder copy can
   miss in-flight database or browser changes.
3. **Back up to the NAS with encryption and Linux metadata preserved.** Keep
   system-owned files, permissions, symlinks, and project hidden files. A new
   full backup must have explicit scope including home and unique system data;
   rerunning the four-root script does not broaden it. An offline disk image
   also preserves the partition table, bootloader, and otherwise missed files.
4. **Put an independent copy of irreplaceable data on OneDrive.** Use encrypted
   archives or an encrypted backup repository; verify cloud quota, upload
   completion, and an actual download. Keep recovery credentials independently.
   OneDrive capacity and access were not inspected. Avoid a loose-file sync as
   the only preservation of Linux permissions, symlinks, or application state.
5. **Verify from another device.** Retrieve the backup without using MSI's
   local keys, run the backup tool's full integrity check, restore representative
   files, and open them. Test database and Resolve restores, game saves, and
   wallet recovery through their respective applications. Record snapshot IDs,
   dates, paths, checksum/check results, and restore results outside MSI.
6. **Freeze the final state.** Close remaining applications, take the last
   incremental backup after this handbook update, and save this documentation
   with it. Capture any changes made after this inventory.

## Before installing Windows

- [ ] Full intended backup scope agreed and completed, including data outside home.
- [ ] Last snapshot/image ID, date, location, and verification results saved elsewhere.
- [ ] Independent NAS login and backup decryption tested from another device.
- [ ] Irreplaceable data has a verified second copy, with cloud upload/download tested.
- [ ] Wallet recovery, browser/account recovery, projects, game saves, Resolve, and databases checked.
- [ ] Final handbook changes are included in the off-machine backup.
- [ ] MSI's remote-service dependencies are retired or moved deliberately.
- [ ] Windows edition/license, TPM2, and Secure Boot capability checked.
- [ ] Windows installation USB prepared separately from backup storage.
- [ ] Network/storage drivers available and backup storage disconnected before disk selection.

Use Microsoft's [Windows 11 download page](https://www.microsoft.com/software-download/windows11)
and [installation guidance](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/ways-to-install-windows-11).
Check the [Windows 11 requirements](https://learn.microsoft.com/en-us/windows/whats-new/windows-11-requirements)
and retrieve drivers for the exact Alpha 15 A4DEK from [MSI support](https://www.msi.com/support/download).
These links were checked on 2026-09-27. The local TPM2 report does not by itself
certify all installation requirements or confirm Windows activation.

During installation, identify the **476.9 GiB Kingston internal SSD by model
and size**, not an assumed Windows disk number. Deleting its Linux partitions

is satisfied. Partition deletion for reinstall is not a certified secure erase
