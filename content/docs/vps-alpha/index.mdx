## Purpose

VPS - Alpha catalogs **everything** installed, configured, and running on the
Contabo server. Like the [MacBook Handbook](/docs/macbook), the goal is
**reproducibility**: if Alpha dies or moves to a new provider, these pages let
you rebuild the exact same setup step by step.

The architecture was verified live on 2026-07-11. Security and recovery posture
was re-audited on 2026-07-21; see the
[dated security audit](/docs/vps-alpha/security-audit-2026-07-21) for verified controls
and unresolved risks.

## Architecture at a glance

```text
                          Internet
                             │
          zero-five.space (Porkbun → Cloudflare DNS)
                             │
      ┌──────────────────────┼───────────────────────┐
      │ :80 / :443           │ :25565                │ :2020
      ▼                      ▼                       ▼
  Traefik v2.11          Minecraft (Java 17)       sshd
      │                  bare metal, systemd     (key-only)
      │
      ├─ hub.zero-five.space ──→ hub-frontend ─→ hub-backend   (VPN-only)
      │                                │
      │                                ├─→ docker-socket-proxy → Docker Engine
      │                                └─→ hub-agent :8765 → systemd + RCON
      │
      ├─ ai.zero-five.space ───→ Open WebUI (host :3000)        (VPN-only)
      │                                └─→ ollama-router (127.0.0.1:11435)
      │                                        ├─→ Ollama VPS    10.8.0.1:11434
      │                                        └─→ Ollama laptop 10.8.0.12:11434
      │                                                  ▲
      │                                       WireGuard tunnel (UDP 51820)
      │
      ├─ brain.zero-five.space → second-brain web → api → PostgreSQL + MinIO
      │
      └─ traefik.zero-five.space → Traefik dashboard (basic auth)

  Telegram translation bot (container) ──→ Ollama VPS 10.8.0.1:11434

  Hermes Agent (native systemd user units)
      ├─ Telegram bot @ZeroFive_OpenClaw_Bot (long-polling)
      └─ web dashboard hermes.zero-five.space (VPN-only, Traefik)
              └─ multi-user accounts + token cost analytics
```

Three kinds of workloads coexist:

1. **Docker Compose stacks** behind Traefik — the hub, second-brain, and the AI stack. See [Docker](/docs/vps-alpha/docker).
2. **Native systemd services** — Ollama, the Minecraft server, and the hub-agent bridge.
3. **A WireGuard VPN** (`wg0`) connecting the VPS (`10.8.0.1`) to the Linux laptop (`10.8.0.12`) so Ollama traffic never touches the public internet. See [WireGuard](/docs/vps-alpha/wireguard).

## Rebuilding from scratch

To recreate the server on a fresh Ubuntu VPS, follow the pages in this order:

1. **[Security](/docs/vps-alpha/security)** — Create the user, harden SSH, enable UFW and fail2ban first
2. **[Docker](/docs/vps-alpha/docker)** — Install Docker Engine and create the external `traefik` network
3. **[WireGuard](/docs/vps-alpha/wireguard)** — Bring up the VPN before Ollama, which binds to it
4. **[Ollama](/docs/vps-alpha/ollama)** — Install natively, bind to `10.8.0.1`, pull models
5. **[Traefik + Hub](/docs/vps-alpha/hub)** — Clone the hub repo; its compose file starts Traefik and the dashboard
6. **[Second Brain](/docs/vps-alpha/second-brain)** — Clone, configure `.env`, deploy
7. **[Telegram Bot](/docs/vps-alpha/telegram-bot)** — Build and run the container
8. **[Hermes Agent](/docs/vps-alpha/hermes-agent)** — Native install, Telegram bot, dashboard unit, accounts plugin, VPN-only Traefik route

> **Note:** the AI stack, Minecraft, and animated-figures no longer rebuild on
> alpha — they live on [gamma](/docs/laptop-gamma) (see its pages). The
> `ai.zero-five.space` Traefik route on alpha proxies to gamma over the mesh.

> **Tip:** DNS (Cloudflare) and the domain survive a server migration — only the A records need to point at the new IP.
