### Recovery and rollback

Infra retains `physics-environment.yml` (all package builds),
`physics-requested.yml` (requested package history), and
`physics-linux-64.explicit.txt` (exact linux-64 package URLs and SHA-256).
The explicit lock preserves the original mix of defaults and conda-forge; the
requested export reports the new base manager's configured channel and is not
an exact rebuild lock. For a reviewed reconstruction at a **new destination**:

```bash
~/miniforge3/bin/conda create -n physics-rebuild \
  --file settings/razer/university/physics-linux-64.explicit.txt
```

Run that command from the infra checkout. Availability of all upstream package
artifacts is not established by the file restore; use the retained snapshot if
an exact artifact has disappeared. Cross-platform or different-prefix rebuilds
need validation. Keep the existing environment until the replacement passes.

Rollback removes the `physics` Jupyter kernel and only the restored environment
through Conda after preserving any new work. The prior Bash file is retained
privately at `~/.local/state/razer-migration/physics/bashrc-before-conda`; remove
only the appended Conda block if rolling back later so other shell edits survive.
Never remove shared environments or the MSI recovery snapshot.

## University and recovery boundaries

The captured [university Wi-Fi plugin](/docs/laptop-razer/university-wifi) includes
enterprise-authentication support and public CA material; on-campus authentication
and private credential enrollment are separate checks. Student identities,
passwords, documents and course projects are not included in the public pack.

Compile an actual course document and run a representative project build before
retiring the MacBook workflow. Undo native installations only after reviewing
shared dependencies. Preserve coursework, lockfiles and private configuration
before removing environments. Docker activation can be reversed after checking
workloads; do not grant broad socket access just to make a smoke check pass.
